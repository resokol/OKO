# Голос дилера — OKO 1.7 preview

Это модуль помощника оператора: голос или введённая фраза → проверка → подтверждение → локальная модель ставок. **Действия не отправляются в PokerVision.** Ключ оверлея даёт чтение, но не принят как токен аккаунта при проверке /v1/auth/me. Авторизованный управляющий адаптер пока отсутствует. Камеры OKO продолжают получать состояние из существующего оверлея.

## Начало без подключения звука

Завершите предыдущий OKO кнопкой «Завершить работу», запустите отдельный EXE preview. Настройки камер/клавиш модульной версии сохраняются. Голосовой модуль по умолчанию остановлен. Он не меняет исходный профиль стабильной 1.5; настройки речи лежат в `<модульный профиль>/modules/speech/settings.json`.

1. В панели «Голос дилера» раскройте начальный снимок. Вводите его **на старте круга торговли, до добровольных действий**; блайнды/анте могут быть уже внесены. Восстановление неизвестной истории посреди улицы не поддерживается.
2. Укажите метку раздачи, улицу, первый действующий бокс, текущую максимальную ставку и минимальное полное повышение (обычно большой блайнд).
3. Отметьте участвующие боксы. Для каждого задайте **остаток** стэка после уже внесённых фишек, внесённое на этой улице, общий вклад за раздачу. Общий вклад включает анте/предыдущие улицы и не меньше вклада текущей улицы. Нулевой остаток — олл-ин. Уже сбросившие игроки сохраняют вклад, но исключаются из дальнейших действий.
4. Нажмите «Задать начальный снимок». Неизвестные значения не заменяются предположениями из оверлея.
5. Введите фразу вручную и нажмите «Разобрать фразу». Перед подтверждением посмотрите итоговую ставку, доплату и бокс. Ошибочную команду можно отклонить или исправить текст.

Пример для проверки расчёта: максимальная ставка 2 000, у бокса1 внесено 1 000 и остаток стэка 10 000. «Бокс 1 рейз до 5000» потребует доплату 4 000. «Бокс 1 рейз на 5000» означает итоговую ставку 7 000, доплату 6 000 и остаток 4 000. Это два альтернативных примера; не применяйте их последовательно как один ход.

## Прямой микрофон и локальная модель

Для Hollyland нужен физический вывод звука в аудиоустройство компьютера. Число гарнитур не определяет способ подключения: модель интеркома ещё нужно установить. Общая смесь разговоров группы ухудшит распознавание; предпочтителен отдельный голос дилера.

1. Откройте панель на этом компьютере в Chrome/Edge.
2. Нажмите «Скачать движок и модель». Windows x64: whisper.cpp1.8.2 CPU (~4МБ) и мультиязычная ggml-base (~149МБ) скачиваются один раз с GitHub/Hugging Face с проверкой опубликованных контрольных сумм. Нужен интернет только для установки. При недоступности сайтов можно скачать файлы отдельно и указать полные пути в «Пути и нагрузка распознавания».
3. Движок Windows использует Microsoft Visual C++ Runtime x64 (MSVCP140/VCRUNTIME140); если он ещё не установлен, потребуется установка этого компонента. Его установка не выполняется автоматически. Обычный OKO по-прежнему включает .NET; дополнительная установка .NET не нужна.
4. Нажмите «Запустить распознавание», дождитесь готовности модели. Она работает отдельным процессом, CPU2потока, GPU выключен; число потоков можно изменить1–4.
5. «Обновить входы» запрашивает разрешение микрофона и показывает аудиоустройства Windows. Выберите вход интеркома, затем «Включить микрофон».
6. Подберите порог выше фонового шума. Конец фразы — после700мс тишины, предел12секунд. Произносите команды раздельно, как при обычной работе дилера. Неясная речь остаётся на проверке, угадывания пропавшего «до/на» нет.

Микрофон захватывается непосредственно браузером, минуя vMix. Вкладка должна оставаться открытой. Аудио отправляется только локальному OKO, затем локальному серверу распознавания; облачного ASR нет. Захваченные WAV не записываются на диск. Закрытие вкладки прекращает захват; кнопка «Остановить голосовой ввод» завершает и распознаватель. Модуль при новом запуске приложения остаётся выключенным.

## Команды и учёт

Поддерживаются «Бокс 2 чек», «Бокс 3 фолд/пас», «Бокс 1 колл», «Бокс 1 ставка 5000», «Бокс 1 рейз до/на 5000», «Бокс 1 олл-ин». Цифры, пробелы разрядов и русские числительные; например «до двадцати пяти тысяч». Колл без суммы рассчитывается по текущему состоянию. Дробные/отрицательные/неоднозначные суммы, суммы при чек/фолд/колл и неполные рейзы не угадываются.

Очередь проверяет действующий бокс, остаток, минимальный рейз и право повторного повышения. Неполный олл-ин не открывает рейз сам по себе; совокупные повышения учитываются по порогу последнего действия игрока. Действия идут по возрастанию мест с оборачиванием. После завершения торговли оператор выбирает действующего на следующей улице и подтверждает её начало; выкладка карт не автоматизируется.

Банки показываются по уровням вкладов, сбросившие не входят в претендентов. Ставка сверх уравненных вкладов во время торговли помечается как ожидающая ответа; при завершении неуравненная часть возвращается в стэк внесшего её игрока и исключается из банка. Возврат не равен выплате выигрыша. Победители, выплаты, показ карт, анте и блайнды не вводятся автоматически голосом в этом выпуске. История хранит последние200 подтверждений. «Отменить последнее действие» возвращает локальное состояние на текущей улице, очищает ожидающие команды. История прошлых улиц сохраняется; отмена не пересекает границу перехода улицы. Новая улица/снимок также очищают очередь; поздняя речь предыдущего снимка не применяется.

Игровой снимок/история живут в памяти, при выходе очищаются. «Скачать состояние и историю» позволяет сохранить JSON. Автоматического восстановления раздачи после перезапуска нет. Запись событий режиссёра — отдельный прежний модуль, это не запись видео или голоса.

## Проверки и ограничения

Браузерный тест проверяет настоящий getUserMedia/AudioWorklet/WAV на искусственном входе и локальную модель распознавателя, подтверждения/отмену, проверки действий, текстовую инъекцию,320/768/1440px. Unit/integration проверки покрывают математику, очередь, повторы и устаревшие фрагменты. Это не замер точности Whisper на реальной речи.

Hollyland, нативный Windows, фактическая скорость/точность русской речи и совместная нагрузка с vMix требуют проверки на вашем компьютере. В облаке скачивание модели Hugging Face заблокировано сетевой политикой; контрольная сумма взята из официального whisper.cpp models/README.md. Автоматическая загрузка модели на пользовательском Windows здесь не проверена. Не заявляем задержку или процент точности без такого измерения. При выключенном модуле ни микрофон, ни процесс ASR не запускаются.
