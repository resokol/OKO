# Распознавание голоса — 1.7.3 preview

1. Подключите PokerVision обычной ссылкой оверлея в существующем разделе «Подключения».
2. В модуле «Распознавание голоса» выберите **микрофон дилера**. «Обновить входы» запрашивает разрешение браузера и показывает устройства Windows.
3. Нажмите **«Включить»**. При первом включении автоматически загрузятся Vosk 0.3.45 и русская модель small-ru-0.22 (~61 МБ). После подготовки модуль начнёт слушать дилера. «Остановить» выключает захват и распознавание.

Стэки, ставки, блайнды, этап и очередь хода поступают автоматически из того же подключения PokerVision по ключу ссылки. Их можно посмотреть в свёрнутом разделе «Данные из PokerVision». Ручных форм ставок/стэков/улиц, подтверждений и отдельной бухгалтерии больше нет.

Дилер говорит «Бокс 1 рейз до 5000», «Бокс 1 рейз на 5000», «Бокс 2 чек», «Бокс 3 фолд». В блоке последних команд основная строка показывает разобранную команду, ниже «Услышано» сохраняет исходные слова модели. Слитные названия вроде «бокстри» и «бокс1» распознаются по известным номерам мест 1–10. Например, «Бокстри рейс на ста» разбирается как «Бокс 3: рейз на 100». «До» и «на» сохраняются как разные команды. Смена раздачи автоматически обновляет контекст и не требует повторного включения микрофона. Фрагменты прежней раздачи/улицы или подключения отбрасываются.

**Отправка команд в PokerVision пока не подключена.** Ключ ссылки открывает данные (HTTP200), но не принят как токен аккаунта (HTTP401). Для автоматического ввода действий нужен поддерживаемый управляющий токен и контракт API; сейчас пользователь располагает только ссылкой оверлея. Распознанная команда не отображается как успешно отправленная.

Звук поступает напрямую с выбранного аудиоустройства компьютера, минуя vMix. Hollyland должен быть подключён к ПК как аудиовход; конкретный способ зависит от модели интеркома. Используйте Chrome/Edge и держите вкладку открытой. Аудио обрабатывается локально, отдельным CPU-процессом, Vosk обрабатывает фразы последовательно; потоки численных библиотек ограничены до одного; GPU не используется.

Дополнительные настройки свёрнуты: движок Vosk/Whisper, порог речи, пути движка/модели; для Whisper — потоки CPU. Если загрузка модели недоступна, можно указать уже скачанные файлы: для Vosk — libvosk.dll и папку модели, для Whisper — whisper-server.exe и ggml-файл. При выборе движка сохраняются его прежние пути. Старые настройки без названия движка переводятся на Vosk; пути Whisper сохраняются для возврата. После выбора нажмите «Включить». whisper.cpp Windows использует Microsoft Visual C++ Runtime x64; обычный OKO включает .NET и не требует его отдельной установки. Микрофон и ASR не запускаются автоматически при старте приложения.

У Vosk ограниченный русский словарь покерных команд и числительных, включая «до» и «на». Неизвестные слова (`[unk]`) не удаляются: неоднозначная команда отклоняется. Это не гарантирует отсутствие ошибок в распознанных словах — всегда проверяйте показанную команду.

Проверены настоящий нативный Vosk с русской моделью в Linux, отдельный процесс, синтетическое аудио, разбор команд и управление через панель. Синтетическая речь тоже распознаётся с ошибками; качество на голосе дилера, Hollyland, задержку на вашем Windows и влияние общей нагрузки на vMix ещё нужно измерить. Установка Windows использует официальные архивы с фиксированными SHA-256 и проверяет полноту распаковки; запуск на реальном Windows в среде сборки недоступен.

Источники: [Vosk 0.3.45](https://github.com/alphacep/vosk-api/releases/tag/v0.3.45), [русская модель](https://alphacephei.com/vosk/models), [официальный резервный источник той же модели](https://github.com/alphacep/vosk-unity-asr/tree/6cc1d5a2a2837e570e32eec4f0ada383a5e94d04/Assets/StreamingAssets). При недоступности сайта модели используется этот резервный источник с той же контрольной суммой. Vosk и small-ru-0.22 распространяются по Apache 2.0; runtime скачивается отдельно.

Микрофон и ASR не запускаются автоматически при старте OKO. Старые версии 1.5/1.6 остаются отдельными загрузками. Перед запуском новой EXE завершите прежнюю OKO через «Завершить работу» — иначе новая программа откроет панель уже работающего экземпляра.
