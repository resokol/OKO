# Распознавание голоса — 1.7.2 preview

1. Подключите PokerVision обычной ссылкой оверлея в существующем разделе «Подключения».
2. В модуле «Распознавание голоса» выберите **микрофон дилера**. «Обновить входы» запрашивает разрешение браузера и показывает устройства Windows.
3. Нажмите **«Включить»**. При первом включении автоматически загрузятся локальный движок и модель (~153 МБ). После подготовки модуль начнёт слушать дилера. «Остановить» выключает захват и распознавание.

Стэки, ставки, блайнды, этап и очередь хода поступают автоматически из того же подключения PokerVision по ключу ссылки. Их можно посмотреть в свёрнутом разделе «Данные из PokerVision». Ручных форм ставок/стэков/улиц, подтверждений и отдельной бухгалтерии больше нет.

Дилер говорит «Бокс 1 рейз до 5000», «Бокс 1 рейз на 5000», «Бокс 2 чек», «Бокс 3 фолд». В блоке последних команд основная строка показывает разобранную команду, ниже «Услышано» сохраняет исходные слова модели. Слитные названия вроде «бокстри» и «бокс1» распознаются по известным номерам мест 1–10. Например, «Бокстри рейс на ста» разбирается как «Бокс 3: рейз на 100». «До» и «на» сохраняются как разные команды. Смена раздачи автоматически обновляет контекст и не требует повторного включения микрофона. Фрагменты прежней раздачи/улицы или подключения отбрасываются.

**Отправка команд в PokerVision пока не подключена.** Ключ ссылки открывает данные (HTTP200), но не принят как токен аккаунта (HTTP401). Для автоматического ввода действий нужен поддерживаемый управляющий токен и контракт API; сейчас пользователь располагает только ссылкой оверлея. Распознанная команда не отображается как успешно отправленная.

Звук поступает напрямую с выбранного аудиоустройства компьютера, минуя vMix. Hollyland должен быть подключён к ПК как аудиовход; конкретный способ зависит от модели интеркома. Используйте Chrome/Edge и держите вкладку открытой. Аудио обрабатывается локально, отдельным CPU-процессом, по умолчанию2потока; GPU не используется.

Дополнительные настройки свёрнуты: порог шума, пути движка/модели, потокиCPU. Если загрузка модели недоступна, можно указать уже скачанные файлы. whisper.cpp Windows использует Microsoft Visual C++ Runtime x64; обычный OKO включает .NET и не требует его отдельной установки. Микрофон и ASR не запускаются автоматически при старте приложения.

Реальное качество и задержку речи с Hollyland/Windows ещё нужно проверить. В облаке протестированы расчленение команд, автоматический контекст, защищённый API и браузерный путь микрофон→WAV→имитатор распознавания. Модель Hugging Face в облачной сети недоступна; автоматическая установка на вашем компьютере пока не проверена. Старые версии1.5/1.6 остаются отдельными загрузками.
